# NEXGUARD – Network Security Center

Website dashboard simulasi keamanan jaringan untuk tugas pembelajaran.

## Fitur
- Dashboard statistik paket, koneksi, ancaman, dan aturan firewall
- Grafik traffic jaringan
- Tambah dan hapus aturan firewall
- Simulasi paket jaringan dan keputusan Allow/Block
- Activity logs dengan pencarian dan hapus log
- IP blacklist dengan fitur blokir dan unblock
- Responsive untuk desktop dan mobile

## Teknologi
HTML, CSS, JavaScript (tanpa backend).

## Menjalankan di komputer
1. Ekstrak folder/ZIP.
2. Buka `index.html` menggunakan browser.

## Publikasi melalui GitHub Pages
1. Buat repository baru di GitHub, misalnya `nexguard-security`.
2. Upload `index.html`, `style.css`, dan `script.js` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. GitHub akan menampilkan URL website.

## Catatan
Website ini merupakan simulasi antarmuka edukasi. Data traffic, alamat IP, dan keputusan firewall dibuat secara lokal di browser; website tidak memantau atau melindungi jaringan sungguhan.
